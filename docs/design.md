# Design fixed before execution

UCI Dry Bean: 13,611 grain records, 16 provided morphology features, seven registered varieties. No raw-photo segmentation is performed. Audit exact feature duplicates and conflicting labels; quarantine conflicts, retain one copy of same-label duplicates before any split. Seed 42, stratified 70/15/15 train/validation/test; train-only scaling. Compare majority, fixed logistic C1, RF200/depth12/leaf2, standardized RBF SVM C10/gamma scale. Select by validation macro-F1. Fit one temperature to selected-model validation scores by NLL; model selection and calibration reuse validation and can overfit it. Inspect test once, report per-class errors/probability calibration and post-hoc permutation sensitivity without reselection. No batch/farm IDs: random grain split cannot establish independent farm/camera generalization.
