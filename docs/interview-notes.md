# Défense en entretien

**Pourquoi un SVM ?** Il dépasse les deux modèles fixes sur la validation ; le choix est figé avant test. Un réseau profond serait inutile sur ces caractéristiques tabulaires sans photos.

**Pourquoi les doublons comptent ?** Des copies exactes traversant les splits peuvent transmettre la réponse. La suppression préalable garde une copie de chaque vecteur et explicite les éventuels conflits.

**Que vaut le score ?** Macro-F1 0,9361 sur 2 032 grains réservés de cette source. Aucun identifiant de lot n'établit une indépendance ferme/caméra ; aucune performance terrain n'est revendiquée.

**Les probabilités sont-elles fiables partout ?** Elles sont calibrées sur validation et évaluées dans la population source. Le score softmax et le vote SVM peuvent différer ; le contrat les expose. Un dataset externe est nécessaire pour une confiance opérationnelle.

Assistance IA déclarée. Maîtriser personnellement splits, standardisation, macro-F1 et limites avant candidature.
